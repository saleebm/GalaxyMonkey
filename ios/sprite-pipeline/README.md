# `sprite-pipeline/`

Asset pipeline for **Galaxy Monkey iOS** (SpriteKit).

Two ingredients flow through here:

1. **Legacy PNGs** — the 46 in-use sprites from the Android source, staged under [`normalized/`](./normalized/) by [`port-legacy.ts`](./port-legacy.ts).
2. **SpriteCook outputs** — HD ports + animations imported / generated through the SpriteCook MCP and HTTP API. Catalogued in [`spritecook-assets.json`](./spritecook-assets.json), keyed by `asset_id`.

## Importing normalized sprites into the iOS app

[`import-to-xcassets.sh`](./import-to-xcassets.sh) copies normalized PNGs into `../GalaxyMonkey/Assets.xcassets/<Name>.imageset/` with a matching `Contents.json`. Imageset names match the cases in [`../GalaxyMonkey/SpriteCatalog.swift`](../GalaxyMonkey/SpriteCatalog.swift). Run from the repo root:

```bash
./sprite-pipeline/import-to-xcassets.sh
```

`SpriteCatalog.texture(for:)` returns `nil` when an imageset is absent, so subsystems gracefully fall back to placeholder primitives. Run the importer (or hand-drop generated assets into the imagesets) to swap in real art piecewise.

## `import-asset.ts` — SpriteCook import helper

Authenticated wrapper around `POST https://api.spritecook.ai/v1/api/assets/import`. Lets agents register a local PNG with SpriteCook (so `animate_game_art` can take it as `asset_id`) without ever inlining the API key. See `SPRITECOOK.md` for usage.

### API key resolution

Resolved in this priority order — first non-empty wins:

1. **`SPRITECOOK_API_KEY` env var** — Bun auto-loads `.env.local` (gitignored). Add the key to `.env.local`.
2. **macOS Keychain** — `security find-generic-password -a $USER -s gma-spritecook -w`.
3. **1Password CLI** — `op read op://gma/spritecook/api-key`.

The helper never echoes the key. On HTTP failure it prints the status + response body but **not** the request headers (which carry the bearer).

## Manifest — `spritecook-assets.json`

Extended schema for the iOS target:

```json
{
  "asset_id": "<uuid>",
  "sha12": "<12 hex of SpriteCook output sha-256>",
  "sha12_local": "<12 hex of source PNG sha-256, if imported>",
  "label": "player_ship_canonical",
  "role": "player | enemy | projectile | pickup | fx | ui | backdrop",
  "asset_path": "GalaxyMonkey/Assets.xcassets/Player.imageset/player.png",
  "output_format": "still | spritesheet | webp | gif",
  "frames": 8,
  "frame_size": [256, 128],
  "fps": 12,
  "loops": true
}
```

`asset_id` is the primary key. `sha12_local` enables idempotent re-imports. `asset_path` connects a SpriteCook row to its position in the iOS bundle.

## Hygiene

- Never commit `.env.local`, never paste `sc_live_…` into any file.
- The bundled output goes into `GalaxyMonkey/Assets.xcassets/<Name>.imageset/` — keep imageset names stable so `SpriteCatalog.Sprite` enum cases keep working.
